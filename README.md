# Stock Data Structures & Algorithms

A collection of C++ programs developed as part of my Data Structures II coursework at Webster University. The projects use stock data to implement and test different data structures and algorithms.

## Projects

### Dynamic Array & Binary Search
Implementation of a dynamic array with operations including insertion, copying, and binary search.

### Linked List & Recursion
A linked list implementation using recursion for insertion, deletion, traversal, and memory cleanup.

### Stock Array Search & Removal
Uses stock data loaded from a file to perform binary search, remove individual elements, and remove ranges of elements.

### Hash Table
Implementation of a hash table for storing and searching stock data, including collision handling with quadratic probing.

### Binary Search Tree
Implementation of a binary search tree for storing and searching stock data.

### AVL Tree
Implementation of a self-balancing AVL tree, including tree rotations to maintain balance.

### Huffman Coding
Uses a Huffman tree to generate codes based on stock data.

### Selection & Quick Sort
Implements selection sort and quicksort in both ascending and descending order.

### Sorting Performance Analysis
Compares the performance of sorting algorithms by measuring their execution time.
